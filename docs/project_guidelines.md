# Project Guidelines - SUPERMANS Mobile

## Standar Pengembangan
1. **Branching Strategy**: Menggunakan Git Flow dengan branch utama `main`, branch staging `dev`, dan branch fitur `feature/*`.
2. **Pull Request Policy**: Setiap perubahan pada branch `main` wajib melalui Pull Request dan melalui proses review tim.
3. **Commit Message**: Gunakan format yang deskriptif (contoh: `feat: add user login model`).
